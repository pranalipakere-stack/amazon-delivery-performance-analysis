# Amazon Last-Mile Delivery Performance Analysis | Power BI

## Project Overview
This project analyzes Amazon last-mile delivery performance using Power BI. The dashboard provides insights into order distribution, delivery times, traffic conditions, weather impact, and delivery agent performance.

## Objectives
- Analyze total orders across different delivery areas.
- Understand how traffic conditions affect delivery time.
- Explore order distribution across weather conditions.
- Compare agent ratings across vehicle types.
- Identify product categories with the highest order volumes.

## Tools Used
- Power BI
- Power Query
- DAX
- Microsoft Excel

## Dashboard KPIs
- Total Orders
- Average Delivery Time
- Average Agent Rating
- On-Time Delivery %
- Average Agent Age

## Dashboard Visualizations
1. Total Orders by Delivery Area – Clustered Column Chart
2. Average Delivery Time by Traffic – Clustered Bar Chart
3. Order Distribution by Weather – Donut Chart
4. Average Agent Rating by Vehicle – Line Chart
5. Order Distribution by Product Category – Treemap

## Key Insights
The dashboard helps understand delivery performance across different areas and conditions. It provides a view of how traffic and weather relate to delivery times and helps compare agent ratings across vehicle types.

## On-Time Delivery Definition
For this project, an order is considered on time when its delivery time is 30 minutes or less. This is a project-defined benchmark and not an official Amazon delivery commitment.

## Dataset
The project uses an Amazon delivery dataset containing order details, agent information, weather, traffic, vehicle type, delivery area, and delivery time.

## Conclusion
This project demonstrates how Power BI can be used to analyze last-mile delivery operations and present useful insights through an interactive dashboard.
